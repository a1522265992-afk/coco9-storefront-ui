# Coco9 · 电脑 3D 交互预览

这是一个独立的首页设计预览，使用 Three.js 和原创参数化电脑模型。机身、键盘、接口、屏幕与转轴都由真实三维几何构成，可以查看背面；不是对照片做透视变换。

## 直接查看

下载本目录的 **[laptop-3d.html](https://github.com/lincwang123-bot/coco9-storefront-ui/raw/refs/heads/main/experiments/laptop-3d/laptop-3d.html)**，双击或拖入支持 WebGL 2 的现代浏览器。文件约 2.74 MiB，代码、模型、纹理和摄影棚环境光全部内嵌，不需要安装依赖、启动服务器或连接网络。页面内的“浏览商品”链接会在新标签打开 Coco9 线上商店。

| 操作 | 效果 |
| --- | --- |
| 停止操作约 3 秒 | 缓慢加速并自动旋转，稳定后约 74 秒一圈；鼠标停在电脑上也会旋转 |
| 移动鼠标、按键或触摸 | 暂停自动旋转；结束操作后重新等待 3 秒 |
| 自动旋转按钮 | 暂停或重新启用自动旋转；暂停状态不会因等待而自动解除 |
| 鼠标拖动 | 水平 360° 旋转、调整俯仰；松开后有轻微惯性 |
| 鼠标滚轮 | 拉近或拉远电脑 |
| 手机左右滑动 / 双指缩放 | 旋转 / 缩放；上下滑动仍可滚动页面 |
| 合上屏幕 / 打开屏幕 | 展示真实转轴开合 |
| 看看商店 / 切回壁纸 | 切换电脑屏幕上的展示内容 |
| 银色 / 深空灰色圆点 | 切换机身材质颜色 |
| 复位 | 恢复默认视角、缩放和打开状态；保留所选配色与屏幕内容 |
| 聚焦电脑后按方向键 | 调整视角 |
| Enter / 空格；Esc / Home | 开合屏幕；复位 |

屏幕内的商店为绘制的示意内容，不包含实时商品、用户、订单、支付或后台数据。预览不会调用业务 API。

## 修改与构建

需要 Node.js 20 或以上版本。在此目录执行：

```sh
npm ci
npm run build
```

生成的 `laptop-3d.html` 可以单独分发。构建时使用固定版本的 Three.js 与 esbuild；依赖已打进文件，访问者无需从 CDN 下载。

| 文件 | 作用 |
| --- | --- |
| `model.js` | 原创模型、金属材质、键盘和屏幕纹理；修改电脑外观从这里开始 |
| `main.js` | 相机、摄影棚光照、空闲自动旋转、鼠标/触摸/键盘交互、屏幕状态、资源释放 |
| `shadow.js` | 根据模型高度生成并模糊接触阴影 |
| `assets/studio_small_03_1k.hdr` | CC0 摄影棚环境光；来源与许可见 `assets/README.md` |
| `shell.html` / `style.css` | 首屏布局、按钮和响应式样式 |
| `build.mjs` | 将脚本、样式与许可打包成单文件 |

模型使用薄边框、带倒角的机身、凹入顶面的键盘和触控板，以及可反射环境的屏幕玻璃。模型仍是原创参数化几何，并非扫描实物或外部成品模型。

模型没有第三方品牌标志，也没有从现有产品照片中提取纹理。代码、模型和程序生成的纹理遵循仓库 MIT 许可；Three.js 的 MIT 许可同时保存在生成文件中。摄影棚 HDRI 使用 Greg Zaal 在 Poly Haven 发布的 [Studio Small 03](https://polyhaven.com/a/studio_small_03)，采用 [CC0 许可](https://polyhaven.com/license)，来源另见 [素材说明](assets/README.md)。

## 性能与边界

- GPU 渲染发生在访客浏览器中；部署时服务器只需提供静态文件。
- 默认在可见且空闲时自动旋转，自动旋转按最多约 30 帧/秒绘制；手动拖动跟随屏幕刷新。手动暂停自动旋转后，停止交互就停止绘制。
- 模型移出可视范围或页面切到后台时停止动画与空闲计时；开合时才更新接触阴影。
- 几何按材质合并，像素比上限为 1.8；启用系统“减少动态效果”时关闭自动旋转、惯性和补间动画。
- WebGL 上下文丢失时显示静态示意及重试按钮；模型和 GPU 资源在页面离开时释放。
- 这是独立实验预览，没有接入六模板入口，也没有替换线上首页。接入主站前仍需检查实际手机、WebKit/Safari 及站点 CSP。
- 已在 Chrome 离线环境完成桌面与手机触摸模拟的功能检查，包括空闲启动、移动暂停、手动暂停、减少动态效果、移出视口、开合、缩放和 WebGL 恢复。后台标签页暂停逻辑尚未在真实前后台切换中验证。
