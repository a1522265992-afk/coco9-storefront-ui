GET STARTED

看效果，或开始做自己的店。

01 / 只想看看

这个文件就够了

双击 preview.html，选择六张缩略图中的任意一张。用「桌面 / 手机」按钮切换尺寸，点击商品可打开详情。整个预览可离线使用。

02 / 想改成自己的

下载源码，再修改

下载开源仓库 ZIP 并解压。安装 Node.js 20 或以上，在项目目录运行 npm start，用浏览器打开 http://127.0.0.1:5173。

商品示例在 demo.js，布局在 src/themes/，样式在 src/styles.css。详细接入步骤见仓库 README。

03 / 准备上线

连接你自己的业务

这份开源项目提供 UI 和交互示例。真实商店还需要商品、用户、订单与支付服务；价格与库存由你的服务端校验。可将完整静态文件部署到支持 HTTPS 的托管服务。

修改源码后运行 npm run build:preview，重新生成这个离线文件。
